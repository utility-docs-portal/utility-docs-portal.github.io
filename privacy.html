Privacy Policy

Last updated: October 20, 2026

1. Purpose

Assistente Backup Rclone is a personal-use utility for transferring locally encrypted backups to the account owner's Google Drive.

2. Google Drive Access

The application uses Google OAuth with the drive.file scope to access files created or used with the application.

Depending on the operations initiated by the user, it may create, read, update, or delete authorized Google Drive files.

3. Data Handling

Backup contents are encrypted locally using Restic before upload.

OAuth credentials and access tokens are stored locally by Rclone. The application does not use a separate developer-operated server to collect Google Drive file contents.

Google Drive receives the encrypted backup files and associated file metadata, such as names, sizes, and timestamps.

4. Data Sharing

The application does not sell user data or share Google Drive contents with advertisers. Google processes stored files according to its own applicable terms and privacy policies.

5. Data Retention and Deletion

Backup files remain in the user's Google Drive until they are removed by the account owner. Revoking application access does not automatically delete previously uploaded files.

6. Revoking Access

The account owner can revoke the application's Google account access at any time through Google Account security settings.

7. Contact

Project information is available at the project repository .

This personal utility is not affiliated with Google.
