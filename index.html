Assistente Backup Rclone

A personal-use utility for securely backing up files to the user's own Google Drive account.

How it works

Backup files are encrypted locally using Restic before being transferred to Google Drive through Rclone.

Google Drive access is used to manage backup files authorized by the account owner. The application does not operate a separate server for collecting personal files.
